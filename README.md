## ☁️ Cloudflare Stack

I am building with the Cloudflare developer platform and learning how its integrated services can be used to create fast, secure, and globally distributed applications:

- **Workers & Hono** — lightweight, type-safe APIs and edge applications
- **D1** — serverless SQL databases
- **KV** — globally distributed key-value storage
- **R2** — S3-compatible object storage without egress fees
- **Durable Objects** — stateful coordination and real-time application logic
- **Queues** — reliable background jobs and asynchronous processing
- **Workers AI & Vectorize** — AI inference, embeddings, and vector search
- **Pages & Pages Functions** — full-stack web deployments
- **Access & Zero Trust** — application security and identity-aware access
- **Wrangler** — local development, deployment, configuration, and infrastructure management
